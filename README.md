# PNG Parser

Краткое описание проекта: программа на C для анализа PNG-изображений и извлечения информации об их структуре.

## О проекте

Здесь будет описано назначение программы, её основные задачи и то, какую информацию она извлекает из PNG-файлов.

## Принцип работы

Общее описание процесса обработки изображения: от передачи входного файла через аргументы командной строки до анализа данных и формирования текстового файла с результатами.
